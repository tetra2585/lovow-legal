よくある質問

機種変更しても記録は引き継げますか？

はい。「設定 → アカウント」から Apple または Google でアカウントを作ると、記録が自動でバックアップされます（無料）。新しい端末で同じ方法でログインすると元に戻ります。

パートナーとつながるには？

「設定 → パートナー → 招待を送る」で招待を作り、相手に送ってください。相手はリンクを開くか、「招待コードを入力する」からコードを入れます。つながるには、二人ともアカウントが必要です。

複数の人とつながれますか？

無料版では1人、Premium では最大5人とつながれます。相手ごとに「二人の空間」があり、ホームの上にある名前で切り替えられます。ある人との記録が、別の人に見えることはありません。Premium は、購入した方と最初につながった相手の二人で使えます。Premium が終わると、2人目以降との空間は「読むだけ」になります（記録は消えません）。

「自分だけ」の宣言は相手に見えますか？

見えません。内容も、存在も表示されません。「サプライズ」は、届けるまで「あなたのための宣言がある」ことだけが伝わります。

相手から嫌がらせを受けたときは？

「設定 → パートナー」で、その相手の「通報する」から運営者にお知らせください。内容を確認し、必要に応じて利用停止などの対応をします。「ブロックする」を選ぶと、つながりが解除され、今後その相手とはつながれなくなります。通報やブロックは相手に通知されません。急ぎのときは、上のメールアドレスにもご連絡ください。

パートナーとのつながりを解除するには？

「設定 → パートナー」で、相手ごとの「つながりを解除する」から解除できます。共有していた記録はお互いに見えなくなり、自分が書いた記録は手元に残ります。

Premium を解約するには？

iPhone の「設定 → [ご自身の名前] → サブスクリプション → LOVOW」から解約できます。更新日の24時間前までに解約すれば、次の期間の料金はかかりません。解約後も、これまでの記録や写真は残ります。

購入した Premium が反映されません

Premium の画面の「購入を復元」をお試しください。

言語を変えるには？

「設定 → 言語」で日本語と English を切り替えられます。

通知が届きません

「設定 → 通知」でオンになっているか、おやすみ時間に入っていないかをご確認ください。iPhone の「設定 → 通知 → LOVOW」で通知が許可されているかもご確認ください。

アカウントを削除するには？

「設定 → アカウント → アカウントを削除」から、アカウントとすべての記録をすぐに削除できます。元には戻せません。サブスクリプションは自動では解約されないため、先に解約してください。
